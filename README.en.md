# Tokyo Railway Real-time Information System

A Tokyo railway real-time information system built with Vue.js, providing operation status and basic information for railway systems across the Tokyo area.

## Features

- Real-time train delay information
- Support for multiple railway systems:
  - Tokyo Metro (9 lines)
  - Toei Subway (4 lines)
  - JR East (major lines in the Tokyo area)
  - Major private railway lines
- Detailed route information
- Latest railway news

## Tech Stack

- Vue 3
- Vue Router
- Element Plus
- Modern CSS Features

## Development Setup

### Install dependencies

```
npm install
```

### Run in development mode

```
npm run serve
```

### Build for production

```
npm run build
```

### Lint code

```
npm run lint
```
