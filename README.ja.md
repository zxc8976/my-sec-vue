# 東京鉄道リアルタイム情報システム

Vue.js で作った東京鉄道リアルタイム情報システムです。東京エリアの各鉄道の運行状況と基本情報を提供します。

## 機能

- 列車の遅延情報をリアルタイムで表示
- 複数の鉄道に対応：
  - 東京メトロ（9路線）
  - 都営地下鉄（4路線）
  - JR東日本（東京エリアの主要路線）
  - 主要私鉄の路線
- 詳しい路線情報
- 最新の鉄道ニュース

## 技術スタック

- Vue 3
- Vue Router
- Element Plus
- Modern CSS Features

## 開発環境のセットアップ

### 依存関係のインストール

```
npm install
```

### 開発モードで実行

```
npm run serve
```

### 本番用ビルド

```
npm run build
```

### コードチェック

```
npm run lint
```
